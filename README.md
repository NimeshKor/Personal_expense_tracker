# Personal Expense Tracker

A simple Python desktop app to record and keep track of daily expenses.

## Features
- Add and delete expenses
- Organize spending by category
- Search expense records
- View total spending, transaction count, and average expense
- See a category-wise spending summary
- Save records locally using SQLite

## Requirements
- Python 3
- Tkinter and SQLite (usually included with Python)

## Data stored

Expense records are stored in `expenses.db` in the same folder.

## Built With
Python, Tkinter, and SQLite.
